# 📝 MyBlog – Full Stack Blog App

## 📌 About Project
MyBlog is a full-stack blog application where users can **sign up, sign in, add blogs with image upload, view blogs, and delete their own blogs**.  
Authentication is handled using **cookies**, passwords are securely stored using **bcrypt hashing**, and the backend runs with **nodemon** for faster development.  
The UI is built using **HTML + Tailwind CSS** with a modern dark theme.

---

## ✨ Features
- User Authentication (Signup / Signin / Logout)
- Password hashing using **bcrypt**
- Cookie-based login session
- Add blog with **title, content & image upload**
- View all blogs in card layout
- Delete blog functionality
- Responsive dark UI (Tailwind CSS)
- Live reload using **nodemon**
