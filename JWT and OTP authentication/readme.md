# 🛡️ JWT & OTP Authentication System

## 🔹 About Project
This project is a **secure OTP-based authentication system** with **JWT token-based authentication**.  
Built with **React frontend** and **Node.js backend (Express + MongoDB)**.  

✨ **Features:**
- 📝 User Signup & Signin with password hashing
- 📧 OTP verification via email
- 🔑 JWT-based authentication with cookies
- 🔒 Protected routes
- 🚪 Logout functionality
- 🖼️ Clean UI with cards showing user info
